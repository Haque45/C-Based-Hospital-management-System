# Hospital Management System (C++ Console Application)

This is a C++ console-based Hospital Management System that allows basic management of doctors and patients. It uses object-oriented programming principles to add, display, and update hospital records through a simple text-based interface.

## Features

- Add and display doctors with their specialties
- Add and display patient information
- Update patient age and gender based on name search

## Technologies Used

- Language: C++
- Platform: Console (CLI)
- OOP Concepts: Classes, Encapsulation, Vectors

## How to Run

1. Clone or download this repository.
2. Compile the program using a C++ compiler:
   g++ hsp.cpp -o hospital
3. Run the executable:
   ./hospital
   
## Note

- All data is handled in memory (no file/database storage).
- Intended for educational or demonstration purposes.
